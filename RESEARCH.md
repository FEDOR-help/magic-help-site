## Что не так с текущим сайтом (диагностика)
1. Бардак внимания: нет единой цели — «витрина» с 6 услугами + практиками + этапы.
2. Слабый hero: «Магическая помощь» + теги, нет обещания ценности для посетителя.
3. Нет доверия вверху (соцдоказательства, цифры) — решения не принимаются без него.
4. Отзывы выглядят «взятыми с потолка», нет измеримых/конкретных деталей.
5. Нет FAQ — не снимаются возражения скептика (главный барьер в этой нише).
6. CTA одно и внизу слабо; нет повторных призывов после блоков.
7. Georgia/serif + сплошной текст — устаревше и «дешёво», несовременно.
8. Нет предложения оффера (что получаю прямо сейчас), нет «бесплатного входа».

## Лучшие практики (из involve.me + обзор 2025-2026)
- **One-goal rule**: одна цель на страницу, минимум ссылок/меню — меньше отвлечений,
  больше действий. Один главный CTA.
- Структура: **Промис (hero) → Доказательство ценности → Выгоды → Соцдоказательства →
  повторный CTA → детали/FAQ → финальный CTA**.
- Hero: главный заголовок (обещание) + подзаголовок + визуал + CTA + микро-доверие
  («уже в группе 500 человек», логотипы/цифры).
- Соцдоказательство размещать и рано (в hero строчкой), и у CTA (в момент решения).
- FAQ — снимает страх/возражения, критично для доверия в «магической» нише.
- CTA повторять: hero → середина → конец. Делать заметным и единственным.
- Дизайн-тренды 2026: чистый современный look, крупная типографика, воздух/отступы,
  единая цветовая система, имиджи вместо эмодзи, аккуратные карточки, мобильная версия.

## Новая структура (прототип)
1. **Hero** — обещание: «Практическая помощь и поддержка в трудной жизненной ситуации.
   Бесплатно присоединяйтесь к сообществу „Магическая помощь"». Заголовок с выгодой,
   подзаголовок, СТА-кнопка «Присоединиться к группе» (t.me/+wRq61Q4JwfNjMGYy),
   микро-доверие (счётчик/признак), аккуратный имидж (не китч).
2. **Что вы получите в группе** — выгоды членства (причины вступить): обсуждения,
   практики, ответы мастера, поддержка. (3-4 пункта с иконками, не эмодзи-китч).
3. **Кому будет полезно / для кого** — сегменты, чтобы посетитель узнал себя.
4. **О мастере / Фёдоре** — короткое личное: подход, принципы, честность, конфиденциальность.
5. **Отзывы** — конкретные, с деталями (ситуация → результат), вызывающие доверие.
6. **FAQ** — снимаем возражения (это безопасно? сколько стоит? подойдёт ли мне? конфиденциально ли?).
7. **Финальный CTA** — ещё раз «Присоединиться к группе» + контакт мастера @fedormagic.
8. **Футер** — по правилу лендинга: минимум ссылок, юридическая строка-дисклеймер (это
   эзотерическая/духовная помощь, не медицинские услуги, не гарантии).

## Принципы реализации
- Один главный CTA-цвет, повторяется; вторичные (мастер) менее заметны.
- Современная типографика (кириллица: системный стек / интер). Без «шаблонного» serif-китча.
- Единая светлая/нейтральная палитра с одной акцентной (не кислотной) «магической» нотой.
- Воздух, отступы, сетка. Мобильная адаптация. Умеренные анимации.
- Имиджи: по возможности реальные/сгенерированные качественные, НЕ эмодзи-каша.
- Дисклеймер об ответственности (эзотерика ≠ медицина) — повышает доверие и законность.
